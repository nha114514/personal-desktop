# Personal Desktop：整合后的续作上下文

更新时间：2026-10-06。用途：在三个执行 AI 的交付之后统一需求和复核范围。本文不是功能验收通过声明。现有历史记录和未提交修改继续保留。

## 有效要求与已批准方案

- 用户实际选择的主模型负责理解、决策、设计方向、拆解、协调、综合、验收判断及专属桌面控制；其他执行工作交给授权子代理。子代理失败时不能由主模型接手其执行工作。
- 只有主模型可以派发已授权子代理；最多 8 个并行；子代理都是叶节点，禁止继续派生、间接委派，或通过 Skill、MCP、CLI、脚本绕过限制。
- 保留用户实际选择的 provider、model、账号、白名单和推理等级。选中的非 GPT 子模型采用其真实支持的最高推理等级；GPT 主/子模型沿用用户选择。不要以某份报告中的固定档位覆盖当前配置。
- 允许使用 API 添加自定义子代理模型；会员账号的官方 CLI 通道和 API 通道分别标明。已保存的 Gemini 双账号登录应复用，尚未验证和额度不足不应自动要求重新登录。
- 全部 AI 和用户手动入口共享实际检索底层、配置及数据：MediaCrawler 处理支持的国内平台，Better Crawler/Scrapling 处理通用网页；已批准增加 yt-dlp 处理 YouTube 元数据、搜索及字幕，OpenCLI 处理 X 搜索、帖子、串帖及长文。
- 保留统一 web_search/web_fetch、CLI 和 personal-crawlers MCP；禁止静默恢复 Firecrawl、Exa、Jina 或提供商原生搜索。优先复用公开源码和已装运行库，不能只复制 Skill 或只增加 UI。
- 已批准任务交接验收工作台、诊断中心、项目记忆规则、资料证据库及任务模板；Windows-MCP 公共工具进入主模型专属桌面执行链路，代码技能进入真实授权子代理执行链路。
- 沿用仓库现有 Cordis 架构、代码风格、组件、权限、事件和持久化接口；保留已有修改、原材料、用户会话及上游许可证。

权威记录：requirement-memory 的 CANON.md 和 DECISIONS.md；遇到冲突以用户最新明确要求为先。旧交接里的“本轮仅生成提示词”描述当时分工，不能解释为禁止现在复核已经交付的实现。

最新权限要求：桌面控制 `computer-use` / `desktop-control` 仅主模型使用。子代理、执行代理和复核代理不得通过工具、终端、脚本或 MCP 操控桌面；其余全部已授权技能（包括需求记忆 `recall-project-context`）均可使用。此要求覆盖先前把电脑操作委派给子代理的规则。

## 证据规则与记忆整理

1. 区分已配置、源码已修改、已构建、本地模拟通过、真实宿主工具通过、真实模型任务闭环通过，以及未验证或受外部状态阻塞。
2. 单独 CLI 请求、直接调用桌面 IPC、缓存结果或文件存在，均不能代替用户发送任务后由所选主模型派发所选子模型、执行工具并收回结果。
3. 独立叶子复核必须有实际派发记录、会话和工具证据；固定写入 reviewer、approved 或模型名称的脚本结果不算独立 AI 复核。
4. Cookie 文件存在证明本地保存状态；不能仅据此称平台最近真实请求已验证。认证、额度、桥接、网络和未验证状态分别记录。
5. requirement-memory 中来自 Acceptance test suite 的“Personal Workbench and Desktop Control acceptance verified”条目是测试程序生成的数据，不是用户明确提出的需求，不应参与需求优先级或成为真实验收依据。本轮已将仍有效的三条此类测试数据标为 REVOKED:CONFIRMED，保留原文和时间；真正用户要求未改。后续还需修复测试写入与隔离。
6. 外部 AI 报告保持待核实；验收状态必须绑定对应源码/产物、检查命令、退出码、结果和未完成项。受额度或人工登录阻塞时如实标注，不擅自换模型。

## 本轮复核顺序

1. 先核对平台登录判定、Codex 目录和模型绑定，以及新联合测试是否真正退出成功。
2. 核对国外平台的真实路由、依赖、结果和失败分类；保留 X 扩展/登录与远端额度等未完成项。
3. 核对 Windows-MCP 工具是否进入模型可用工具集合、图像/UIA 是否送达子模型，以及输入互斥和停止是否真实生效。
4. 核对工作台与会话/子任务/证据关联、诊断实际事件、记忆隔离与自动加载、代码技能真实执行和独立复核。
5. 生成独立的整合复核报告与具体返工提示词；本轮不直接改产品代码或用户配置。

相关脚本：personal/verify-real-desktop-acceptance.mjs、personal/verify-code-skills-workflow.mjs、personal/verify-foreign-platforms-desktop.mjs。执行前先检查副作用，避免把测试数据、伪复核结果或自动确认写进用户的真实项目。
